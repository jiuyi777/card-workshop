# ✦ 提示词工坊 v0.1.0

一个独立的 SillyTavern 客户端扩展，按 **写 → 存成条目 → 拼装预设** 的方式制作对话补全提示词。

## 安装

1. 下载本 ZIP，解压后取得 `prompt-workshop` 文件夹。
2. 放到酒馆用户扩展目录（常见为 `SillyTavern/data/default-user/extensions/prompt-workshop/`；旧版本可能使用 `public/scripts/extensions/third-party/prompt-workshop/`）。
3. 刷新酒馆，在扩展（魔棒）菜单中选择 **提示词工坊**。如扩展菜单未加载，右下角会出现独立入口。
4. 本 ZIP 是源码包，不是可直接通过酒馆“Git 仓库链接安装”使用的网址。想用 URL 安装，请先将文件夹推送到自己的 GitHub 仓库，再粘贴仓库地址。

无需服务器端插件，无需单独 API Key；**与写卡工坊可同时安装**，两者使用不同的设置键、文件名和样式前缀。

## 四个页面

### 创作

输入需要实现的功能，选择模块型、规则型或文风型，选用酒馆当前连接或在「设置」中选定的连接配置文件。生成的正文可以继续编辑；保存时可填名称、`system/user/assistant`、标签、注入位置和 D 深度。生成过程不会直接改变当前聊天或预设。

当写作用预设被选择时，会像写卡工坊一样抽取选定预设中**启用的非标记条目**作为额外上下文；默认不叠加其他预设。

### 条目库

搜索、按标签筛选、编辑、删除，或从酒馆**当前聊天补全预设**、本地原生 JSON 批量导入非标记正文条目。导入条目默认不进入正在使用的拼装方案；名称和正文保留，额外原生字段也尽量保留。

### 拼装

维护多套拼装方案，跨方案复用条目。每套方案分别保存选择开关、启用开关与顺序。桌面可拖动条目，移动端可点 ↑ / ↓ 排序。

提示词位置：

- 头部：在 `main` 之后。
- 角色定义之前：在角色定义相关的标记前。
- 聊天记录之前：在 `chatHistory` 之前。
- 聊天记录之后：在 `chatHistory` 之后。
- 末尾：在相对顺序最后。
- 聊天内注入：`injection_position = 1`，用 `injection_depth`（D0/D1/D2）与 `injection_order` 控制。此类条目在 `prompt_order` 中放在相对条目之后，但实际发送位置由酒馆的深度机制决定。

**导出**：下载原生 `prompts` + `prompt_order` 结构 JSON，保留底稿的原生模型参数和特殊标记，不需要本扩展也能在 SillyTavern 中导入。

**另存为酒馆新预设**：调用当前酒馆提供的 `getPresetManager('openai').savePreset` 创建新预设（若同名会先确认）。

**覆盖当前预设**：只在明确确认后覆盖，并预先下载该预设原版 JSON 备份。覆盖时以**当下选中的预设**为底稿，不使用「设置」页的固定底稿，避免误覆盖与丢失其他原有参数。

### 设置

可选酒馆「连接配置文件」与写作用预设。默认生成调用走酒馆 `generateRaw`，配置文件调用走 `ConnectionManagerRequestService`，与写卡工坊同一路线。

- **动态底稿**：默认采用酒馆当前聊天补全预设。如果无法读取，就用插件内置的原生基础结构。
- **固定底稿**：手动导入 JSON 或从当前预设固定快照。用于持续迭代同一个模板，保留宏、角色/world info/chat history 标记及其他参数。
- **库备份**：专有 JSON，含方案、标签、条目、草稿与固定底稿（如有），可另行备份/恢复。和可导入酒馆的预设 JSON 是两种不同文件。**固定底稿或原生导出有时会包含代理密码、自定义请求头等连接敏感参数，请勿公开分享。**

## 兼容范围

- SillyTavern 酒馆 **Chat Completion** 对话补全预设，包含角色上下文标记、聊天历史标记和支持两种角色模式的 `prompt_order`（100000 / 100001）。
- 原生条目字段 `role`、`content`、`name`、`identifier`、`injection_position`、`injection_depth`、`injection_order`、`injection_trigger`；聊天内深度适用于支持它的酒馆版本。
- 连接兼容性由**酒馆本身**支持的 API 后端与已设置的模型决定，不在本插件内直连第三方 API。
- 不支持把 Text Completion 的 Instruct / Context 模板直接导入为聊天补全预设。
- 不修改写卡工坊、现有角色卡、世界书或八股清理设置；八股清理自动联动尚未接入。

## 数据与测试

条目保存在 `extensionSettings.promptWorkshop`，通过 `saveSettingsDebounced` 持久化。没有外部数据库，不会主动向第三方服务发送完整条目库；**只有按下 AI 生成按钮时**，发送当前需求、草稿以及用户自行选择附加的写作用预设条目到酒馆配置的模型后端。

在源码根目录执行 `npm test` 可以运行结构与拼装逻辑测试（不需要安装任何 npm 依赖）；`npm run check` 检查 JavaScript 语法。还需要在具体酒馆版本的界面里验证菜单挂载、真实 API 请求、原生导入导出、另存与覆盖行为。
