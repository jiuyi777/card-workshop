# 写卡工坊 v0.17.1

SillyTavern 扩展。在插件里写卡：一句话脑洞 → 构想 → 标签 → 人设 → 世界观 → NPC → 路线 → 基调与规则 → 开场白 → 试玩 → 质检 → 导入酒馆 → Discord 简介。

和 [八股清理](https://github.com/jiuyi777/bagu-cleaner) 联动：装了八股清理就直接用它的规则和“我的八股词”改写，没装就跳过。

## 安装

在酒馆的 **扩展 → 安装扩展** 里粘贴本仓库地址，刷新酒馆。

手动安装：把整个文件夹放进 `SillyTavern/data/default-user/extensions/`（或 `public/scripts/extensions/third-party/`），刷新。

想联动八股清理，两个扩展装在同一个目录下即可（八股清理的文件夹名保持 `bagu-cleaner`）。

## 用法

扩展菜单（魔棒）→ **写卡工坊**。打开是目录：上面有“下一步”按钮，下面每一步一个入口，点进去是这一步的页面，页面底部有“下一步”。

1. **一句话构想**：输入脑洞，可以先点“先问我几个问题”，AI 针对你的脑洞问几个关键问题，点选或自己写，再“带上回答生成构想”；也可以直接生成。得到 3 个方向不同的构想，标签自动勾好。没想法就点“掷骰子”：随机抽几个标签，AI 问你 3 个问题，你点选或自己写答案，再生成构想。
2. **标签**：实心是从你那句话里识别的，虚线是 AI 推荐的，带问号的是 AI 推测的必填项（性向、人数等），点一下开关。AI 提出的新标签可以一键收录进你的标签库。
3. **主要人设**：先“出问题”，每题有 3 个可以点的答案，这一步决定这个角色和刻板印象哪里不一样。然后生成人设：概要（蓝灯）+ YAML 人设（绿灯，矛盾建模模板）。
   - **加新角色**：人设页点“加一个主要角色”，写名字和一句设想（都可以空着：名字让 AI 起，设想空着就补一个卡里缺的人），点“写这个角色”。会参考已有的角色和整张卡（改已有的卡时也一样），写回时多一个“人设·名字”条目。写完会提醒你：角色关系网、路线里还没有 TA。
4. **展开经历**：人是被经历塑造的。人设页每个角色下面会显示经历写了几段、多少字，太少就点“展开经历”：单独调一次 API 只写经历，4–7 段，每段写清发生了什么 → 留下了什么 → 现在怎么冒出来，每条矛盾轴都要在经历里找到来处，写完换进人设的 life_story。一键出卡时经历太少会自动展开（设置里可以关）。
5. **可预测性测试**：先只把角色的类型标签给 AI，让它猜这类角色的刻板写法；再让 AI 按意思（不看字面）比对人设，撞上的句子标出来，可以一键重写。
5. **世界观 / NPC / 路线 / 基调与规则 / 自由模块**：路线可以自己写，也可以先填身份、时期和一句主题，点“写这条”只写这一条（别的路线不动）；都可以一键生成，也可以手改。每个 NPC 都要有剧情功能和自己想要的东西。NPC 页可以“加一个 NPC”，写上名字和一句设想（都可以空着），点“写这个 NPC”只写这一个，别的不动；已经写好的也可以单独“重写这个”。每条路线 = 一个 user 身份 + 一个时期。
6. **开场白**：先“想 5 个梗”，勾选喜欢的、直接改字，或者自己写梗，再“扩写勾选的”；扩写的加在后面不覆盖。也可以“不想梗，直接写”。用你绑定的“开场白预设”（开场白页顶部就能选）。没有路线也能写：开场白页有“不分路线”一组，想梗、扩写、直接写都可以，不会自动加路线；有路线时点“写一个不分路线的开场白”。
7. **试玩**：选一个开场白开始，用“开场白预设”跑几轮。发出去的设定和导入酒馆后一样：蓝灯条目、这条路线、最近几条消息里提到关键词的绿灯（页面上能看到这一轮发了哪几块、多少 token）。可以自己打字，也可以点“AI 帮我写一句”放进输入框改了再发，或者让 AI 扮某种玩家（普通 / 唱反调 / 话少 / 乱来）自动跑几轮，每轮 2 次调用。最后一条不满意点“重来这条”，也可以“删到这里”。
   - **试玩点评**：看 OOC、抢话、八股、重复、角色会不会主动推剧情，每条问题标出是第几条消息、出在卡的哪一部分。点“带着这条意见去……”，意见会填进那一页的“哪里不满意”框，点重写或按意见改就行。
8. **质检**：本地扫描（小动作、口头禅、数字堆砌、无缘由断言、只有禁止没有替代、标签没解释、高频词、世界观形容词、NP 角色太像）+ 八股清理。
9. **导入酒馆**：一键创建世界书（按桶型结构排好蓝灯/绿灯和顺序，只启用第一条路线）和角色卡，自动绑定。之后可以在这里切换路线。导入之后这张卡就算“已导入的卡”：之后在写卡工坊改了什么，同样先检查、只写回勾选的部分，在酒馆里改过的地方不会被改回去。
10. **简介**：生成 3 个标题和一篇 Discord 简介（不用表格，超过 2000 字会提示），可以复制，也可以写进角色卡的作者备注。简介的排版是“简介风格”模板，可以存好几个（提示词 → 简介风格），换风格只重排不调 API；“分段修改”可以改每一段再重新排版。

## 卡的类型：单人卡 / 多人卡 / 无固定角色

标签页顶部可以选卡的类型；不选就自动判断（“卡类型”“人数”标签，以及主要角色有几个）。

- **多人卡（NP、群像）**：规则库的“多人卡”会自动插进构想、人设、世界观、NPC、路线、基调、开场白、试玩：每个主要角色占不同的张力位置，彼此之间有自己的账，开场白至少两个人有戏份。人设页底部多一块 **角色关系网**（关系、修罗场、出场规则、群戏里各自说话的区别），蓝灯常驻在人设后面，防止跑成单人卡。一键出卡会自动写。
- **无固定角色（世界卡）**：规则库的“世界卡”会插进对应步骤：世界本身是主角，人物写进 NPC 库（至少 6 个），基调里加叙事和 NPC 现编规则，开场白用旁白视角。人设页可以空着，也可以加几个关键人物。

## 规则库：每一条都可以插拔

提示词 → 规则库。每条规则可以：开关；改内容（恢复默认）；限定只给单人卡 / 多人卡 / 世界卡用；“另外插到”任意步骤（加在那一步提示词的最后）。也可以 **新建规则**，比如把你的世界观教程、某个题材的写法存成一条，插到需要的步骤里。人设模板也在规则库里（“人设模板”），可以换成你自己的。

提示词 → 每一步的提示词 底部可以关掉用不上的步骤（世界观、NPC、路线、基调、试玩、质检、简介）：目录里不显示，一键出卡跳过，写好的内容不丢。

## 做 AU（保留人设内核，换世界观）

目录右上角 **改已有的卡** → 选卡 → **用这张卡做 AU（存成新卡）**。原卡不会被改动。

1. **AU 内核与映射**页：
   - ① **提取内核**：从原卡拆出每个角色的内核（矛盾轴与落点、对 user 的底色、说话方式、决策方式、底线）和外壳（原作世界的身份、组织、地点、道具、经历）。不对就直接改。
   - ② **AU 设定**：一句话 AU，可以先让 AI 问几个问题；标签按 AU 重新选（原作的题材、原型标签不会带过来）。
   - ③ **映射表**：原作 → AU，一条一条换，每条写清在 AU 里怎么长出同样的内核。经历不平移，而是反推。
2. **主要人设**：生成 AU 人设时只给 AI 内核、映射表和 AU 设定，不给原卡全文，避免原作的东西混进来。生成完点 **内核一致性检查**：逐条看内核是保留、偏离还是丢了，有没有原作残留；点 **按检查结果修**。也可以用新题材的标签做可预测性测试，看他有没有变成这个题材的默认角色。
3. 后面的世界观、NPC、路线、开场白照常写，都会带上内核和映射表。也可以直接 **一键出 AU 卡**。
4. 导入时存成一张新卡（默认名“原名（AU）”）。

## 改已有的卡

目录右上角 **改已有的卡** → 选一张酒馆里的卡 → 读取。

- 写卡工坊做的卡：人设、世界观、NPC、路线、基调、模块会认回各自的页。
- 别人做的卡：角色描述当作人设（没有“人设·”条目时），世界书里的其他条目原样放在“原卡内容”页。
- 每一块都能直接改字，或者写意见点 **按意见改**（只改意见说到的地方，不从头重写）。
- **加路线**：“玩家与路线”页点“想几条新路线”，点“加上”，再“给新路线写信息”（原来的路线不动）。
- **加开场白**：开场白页照常想梗、扩写。
- **一键补全**：只给新路线写信息和开场白，原来的内容不动。
- **写回原卡**：“导入酒馆”页先点 **检查要写回什么**：读一遍酒馆里现在的卡和世界书，跟写卡工坊三方比较，按“写卡工坊改了的 / 新加的 / 两边都改了 / 只在酒馆里改过”列出每一处，可以展开看两边的区别。只有写卡工坊改了的和新加的默认勾上；你在酒馆里改过的地方默认保留酒馆的，还会同步回写卡工坊，不会被改回去。勾好再点“写回勾选的 N 处”，没勾的地方一律用酒馆里现在的。写回前自动备份，可以撤销。

**八股清理怎么改**：只挑出含八股的句子（其余一字不动），所有块的句子合在一起，每批 12 句发给 AI，每句带前后句和命中的词；改回来的句子逐句检查（宏有没有丢、是不是原样交回、还有没有必改词），没过的合在一起再发一轮并说明上次哪里不对，还不行就保留原句并列出来。“必改”是写卡工坊的禁用词和八股清理里的“我的八股词”。扫描结果显示文中真正命中的词。

**开场白写完立刻改必改词**：每次写完或扩写完开场白，带禁用词、“我的八股词”的句子马上改掉，只改这几句，新开场白合在一起，通常 1–2 次调用（设置里可以关）。

**每一页底部都有八股检查**：人设、世界观、NPC、路线、基调与模块、开场白（含梗）、简介、原卡内容、AU 内核、我的步骤，每页底下都会本地扫一遍（不调 API），显示禁用词和八股各几处、在哪几块；点 **清理这一页** 只改这一页里有八股的句子（基调与规则里的规则清单不动）。清理前的版本存进各块的“换回上一版”。没装八股清理扩展时只查禁用词。

**局部重写**：在任何大文本框里选中一段，框下面会出现“局部重写”，可以写一句怎么改（比如“改成他嘴硬”），空着就是重写这一段。AI 只交回这一段，前后原样拼回去；缩进、列表符号、YAML 键名丢了会自动补回。

**改了什么**：按意见改、局部重写、重写撞车部分、展开经历之后，这一块上面会显示“改了 N 处”：红色是原来的，绿色是现在的。可预测性测试重写后还会列出针对的是哪几句。

**文风**：提示词 → 文风，可以存好几个（短句白描、口语八卦、贴一段喜欢的文字当样例……）。在“主要人设”页顶部给这张卡选一个：写人设、展开经历、重写撞车、按意见改人设、局部重写人设都会带上；勾“世界观、NPC、路线、模块、开场白也用”就全卡都带。文风只管怎么写，格式要求不变。

**每一块都可以**：在“哪里不满意”框里写意见，点重写（带着意见和上一版重新生成）或者按意见改（只改意见说到的地方）；“换回上一版”能找回最近 5 版（一直点会轮换，转一圈回到最新）；回复被截断时自动续写一次，还不完整会提示你调大最大回复长度。

**一键出卡**：可以先自己写一部分（人设、世界观、路线）再点：构想会以你写好的内容为准，写好的角色和路线不会被换掉；你自己写的人设一个字不动（不自动展开经历、不自动重写撞车、不自动八股清理）。写好一句话后直接点，按顺序跑完构想 → 人设 → 世界观 → NPC → 路线 → 基调 → 开场白 → 可预测性测试 → 八股清理 → 本地扫描，停在导入前让你检查。已经写好的部分不会重写。

草稿自动保存。“新建”会把当前草稿放进历史草稿（保留 8 份），也可以导出成 JSON。目录顶部展开“草稿”：可以打开、删除某一份历史草稿，删除当前草稿（不进历史），或者清空历史草稿。删除只删插件里的草稿，已经导入酒馆的卡和世界书不受影响。

## 设置（写卡工坊 → 目录 → 设置）

- **API**：默认用酒馆当前连接的 API；也可以选“连接配置文件”里的任意一个。
- **两次调用间隔**：默认 3 秒。老是 429 就调大。遇到 429 插件会自动等 15/30/60 秒重试，状态栏显示倒计时。
- **502 / 503 / 504 / 超时 / 断线**：多半是 API 或中转站临时出错，插件自动等 5/15/30 秒重试，状态栏写明原因。三次都失败才报错，已经写好的不会丢，过一会儿再点就行。
- **写卡预设 / 开场白预设**：插件把预设里打开的提示词条目一起发送（聊天记录、角色描述这类占位条目跳过），不会切换你酒馆当前的预设。
- **常驻设定 token 上限**：默认 4000，0 = 不提示。
- **试玩回复长度**：默认 300 字左右。
- **人设放哪里**：世界书蓝灯常驻（默认）/ 角色卡的角色描述 / 世界书绿灯 + 蓝灯概要。
- **玩家写法**：默认 `<user>`。生成时插件会把 `<user>`、`{{user}}`、`{{char}}` 换成占位符再发送，避免酒馆把它们替换成名字，收到后再换回来。

**token**：大一点的文本框右下角显示这一块多少 token，打字时跟着变；每页底部显示这一页合计。目录、质检、导入页显示“常驻设定”合计（蓝灯条目 + 第一条路线 + 角色描述，也就是每次聊天都会发的），超过设置里的上限会标出来，展开能看到每一块多少、绿灯各多少。用酒馆当前 API 的分词器算，算不了时按字数估，前面带“约”。

**说明小字**：默认只在第一次进某一页时显示，之后收起；页面标题旁点“说明”可以临时打开。设置 → 界面 里可以改成一直显示或者不显示，也可以把所有说明再显示一遍。

状态栏会显示：正在做哪一步、转圈、已用秒数、这一步调用了几次、一共调用了几次。

一键出卡大约的调用次数（1v1、两条路线）：构想 1 + 人设 1 + 世界观 1 + NPC 1 + 路线 1 + 基调 1 + 开场白 2 + 可预测性 2（撞车再 +1）+ 八股清理（有八股的条目各 1–2 次，单句重做最多 3 次）。每多一个主要角色 +3～4，每多一条路线 +1。

## 提示词（写卡工坊 → 目录 → 提示词）

- **每一步的提示词**：选一个步骤，直接改或者整段粘贴自己的，自动保存，改坏了点“恢复默认”。可用变量在页面下方。
- **规则库**：通用、矛盾建模、零度写作、开场白、禁令格式、禁用词、直接删。多个步骤共用，改一处全部生效。
  - **禁用词**：每行一个。会告诉 AI 不要用，人设页和质检里会标出来，八股清理也会把它们当必改项。选了同名标签的词不禁（比如选了“神明”）。
  - **直接删**：程度副词这类词，每次生成完直接删掉，不调 API（“十分钟”“七十分”“非常时期”不会误删）。
- **我的标签**：每个维度可以加标签，每行 `名称|触发词,触发词`。
- **我的步骤**：自己加步骤，选放在哪一步后面，目录里会多出单独一页；写提示词模板（可以用 `{{concept}}`、`{{overviews}}`、`{{rules.通用}}` 等变量），产出会成为一个自由模块，导入时写进世界书。勾上“一键出卡时也跑”就会在一键出卡里自动跑。
- **简介风格**：简介的排版模板，可以存好几个。`{{#路线}}…{{/路线}}` 表示没内容就整段省略，`{{路线|引用}}` 表示每行前加 `>`。

## 世界书结构

顺序号按下面的先后连着编（1、2、3……），越大越靠近聊天记录。改已有的卡时，新条目的顺序号接在同类条目后面。

| 条目 | 位置 | 灯 |
| --- | --- | --- |
| 基调与规则 | 角色定义之前 | 蓝 |
| 世界观 | 角色定义之后 | 蓝（拆出的条目有关键词时为绿） |
| 人设概要 | 角色定义之后 | 蓝 |
| 人设·名字 | 角色定义之后 | 蓝（可在设置里改成绿灯或角色描述） |
| NPC·名字 | 角色定义之后 | 绿 |
| 路线·名字 | 角色定义之后 | 蓝，只启用当前路线 |
| 模块·名字 | 自选 | 自选 |

## 测试

```bash
npm install          # 只为了测试装 jsdom 和 jquery
npm test             # 默认在 ../../jiuyi777/bagu-cleaner 找八股清理，用于联动测试
```

- `tests/core.test.mjs`：标签、模板、解析、本地质检、相似度、组装、简介
- `tests/flow.test.mjs`：用假 API 跑完一整张卡
- `tests/bridge.test.mjs`：八股清理联动（真实规则引擎）、API 调用、预设读取、宏保护
- `tests/ui.test.mjs`：在模拟的酒馆页面里加载 `index.js`，点按钮从构想跑到导入、切换路线、简介、设置
