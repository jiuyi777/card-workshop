# 写卡工坊 v0.1.0

SillyTavern 扩展。在插件里写卡：一句话脑洞 → 构想 → 标签 → 人设 → 世界观 → NPC → 路线 → 基调与规则 → 开场白 → 质检 → 导入酒馆 → Discord 简介。

和 [八股清理](https://github.com/jiuyi777/bagu-cleaner) 联动：装了八股清理就直接用它的规则和“我的八股词”改写，没装就跳过。

## 安装

在酒馆的 **扩展 → 安装扩展** 里粘贴本仓库地址，刷新酒馆。

手动安装：把整个文件夹放进 `SillyTavern/data/default-user/extensions/`（或 `public/scripts/extensions/third-party/`），刷新。

想联动八股清理，两个扩展装在同一个目录下即可（八股清理的文件夹名保持 `bagu-cleaner`）。

## 用法

扩展菜单（魔棒）→ **写卡工坊**

1. **一句话构想**：输入脑洞，点“生成构想”，得到 3 个方向不同的构想，标签自动勾好。没想法就点“掷骰子”：随机抽几个标签，AI 问你 3 个问题，你点选或自己写答案，再生成构想。
2. **标签**：实心是从你那句话里识别的，虚线是 AI 推荐的，带问号的是 AI 推测的必填项（性向、人数等），点一下开关。AI 提出的新标签可以一键收录进你的标签库。
3. **主要人设**：先“出问题”，每题有 3 个可以点的答案，这一步决定这个角色和刻板印象哪里不一样。然后生成人设：概要（蓝灯）+ YAML 人设（绿灯，矛盾建模模板）。
4. **可预测性测试**：只把角色的类型标签给 AI，让它猜这类角色会怎么做、怎么说，再和卡里的句子比对。撞上的部分标出来，可以一键重写。
5. **世界观 / NPC / 路线 / 基调与规则 / 自由模块**：都可以一键生成，也可以手改。每个 NPC 都要有剧情功能和自己想要的东西。每条路线 = 一个 user 身份 + 一个时期。
6. **开场白**：每条路线生成几个，用你绑定的“开场白预设”。
7. **质检**：本地扫描（小动作、口头禅、数字堆砌、无缘由断言、只有禁止没有替代、标签没解释、高频词、世界观形容词、NP 角色太像）+ 八股清理。
8. **导入酒馆**：一键创建世界书（按桶型结构排好蓝灯/绿灯和顺序，只启用第一条路线）和角色卡，自动绑定。之后可以在这里切换路线。
9. **简介**：生成 3 个标题和一篇 Discord 简介（不用表格，超过 2000 字会提示），可以复制，也可以写进角色卡的作者备注。

**一键出卡**：写好一句话后直接点，按顺序跑完构想 → 人设 → 世界观 → NPC → 路线 → 基调 → 开场白 → 可预测性测试 → 八股清理 → 本地扫描，停在导入前让你检查。已经写好的部分不会重写。

草稿自动保存。“新建”会把当前草稿放进历史草稿（保留 8 份），也可以导出成 JSON。

## 设置（扩展设置 → 写卡工坊）

- **API**：当前连接，或者“连接配置文件”里的任意一个。用连接配置文件时可以按步骤调温度。
- **写卡预设 / 开场白预设**：分别绑定一个对话补全预设。插件把预设里启用的提示词条目一起发送（聊天记录、角色描述这类占位条目跳过）。开场白建议绑定你平时玩卡用的正文预设。
- **玩家写法**：默认 `<user>`。生成时插件会把 `<user>`、`{{user}}`、`{{char}}` 换成占位符再发送，避免酒馆把它们替换成名字，收到后再换回来。
- **步骤提示词**：每一步的提示词都能改，改坏了可以恢复默认。可用变量见设置里的“可用变量”。
- **规则库**：通用、矛盾建模、零度写作、开场白、禁令格式。多个步骤共用，改一处全部生效。
- **我的标签**：每个维度可以加标签，每行 `名称|触发词,触发词`。
- **我的步骤**：自己加步骤，写提示词模板（可以用 `{{concept}}`、`{{overviews}}`、`{{rules.通用}}` 等变量），产出会成为一个自由模块，导入时写进世界书。

## 世界书结构

| 条目 | 位置 | 灯 | 顺序 |
| --- | --- | --- | --- |
| 基调与规则 | 角色定义之前 | 蓝 | 100 |
| 世界观 | 角色定义之后 | 蓝（拆出的条目有关键词时为绿） | 200 / 210 |
| 人设概要 | 角色定义之后 | 蓝 | 300 |
| 人设·名字 | 角色定义之后 | 绿（可在设置里改成蓝） | 400 |
| NPC·名字 | 角色定义之后 | 绿 | 450 |
| 路线·名字 | 角色定义之后 | 蓝，只启用当前路线 | 500 |
| 模块·名字 | 自选 | 自选 | 600 |

## 测试

```bash
npm install          # 只为了测试装 jsdom 和 jquery
npm test             # 默认在 ../../jiuyi777/bagu-cleaner 找八股清理，用于联动测试
```

- `tests/core.test.mjs`：标签、模板、解析、本地质检、相似度、组装、简介
- `tests/flow.test.mjs`：用假 API 跑完一整张卡
- `tests/bridge.test.mjs`：八股清理联动（真实规则引擎）、API 调用、预设读取、宏保护
- `tests/ui.test.mjs`：在模拟的酒馆页面里加载 `index.js`，点按钮从构想跑到导入、切换路线、简介、设置
